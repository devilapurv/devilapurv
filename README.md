### 1. 🏙️ CivicPulse India — Civic Complaint Intelligence
**Technologies:** Python | Pandas | Scikit-learn | Machine Learning | Streamlit

- Analyzed **326,156 civic complaints** across **198 Bengaluru wards** using historical 2023–2024 data.
- Implemented **K-Means clustering, Isolation Forest, and Random Forest regression** for ward analysis, anomaly detection, and complaint forecasting.
- Developed a priority scoring system to identify wards requiring greater attention.
- Built an interactive Streamlit dashboard featuring complaint trends, anomaly alerts, and actionable recommendations.
- Achieved an **R² score of 0.845** on the historical forecasting test set.
